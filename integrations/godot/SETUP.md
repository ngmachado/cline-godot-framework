# Godot MCP setup

Follow [README step 2: Set up MCP in Godot and Cline](../../README.md#2-set-up-mcp-in-godot-and-cline) for plugin installation, Cline configuration, and the read-only connection-test prompt.

The tutorial uses NPGameDev Godot MCP Toolkit and its `@npgamedev/godot-mcp-server` bridge. The user installs and connects them; this framework does not include or configure them.
