# Art direction and style governance

**Primary role:** Creative Artist. **Use when:** a game needs a style guide, new look, consistency pass or mood definition.

## Required inputs

- Game vision, target player/camera and accessibility goals.
- Target engine/platform and production budgets.
- Approved visual references or desired artistic direction.

## Procedure

1. Identify the emotional tone and visual hierarchy the gameplay needs to communicate.
2. Specify silhouette, line/form language, proportions, material response, color contrast and lighting conventions.
3. Define reference directions for characters, props, environments, UI and VFX without copying protected assets.
4. Set technical presentation rules: resolution, texture density, texture filtering, rig/pivot units and export conventions.
5. Provide a small comparison set of approved in-game visual targets or clearly labeled design references.
6. Record decisions in `project/ART_DIRECTION.md` and create checklists for downstream asset skills.

## Deliverables

- Art-direction guide with palettes, proportion/lighting rules and illustrative references where available.
- Production rules and quality acceptance checklist.

## Validation / done criteria

- [ ] Style supports gameplay legibility from intended camera.
- [ ] Character/environment/UI elements remain coherently distinguishable.
- [ ] Specified formats and targets are feasible on the selected platform.

## Guardrails

- Do not switch aesthetic direction without Director/user authorization.
- Concept art is not proof of shipped in-engine visual quality.

**Related skills:** character-design, environment-design, ui-design.
